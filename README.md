# 比良坂神社 Webサイト

架空の神社「比良坂神社」の紹介サイトです。学校のオリジナルサイト制作課題(前期審査会用)として制作しました。

## ページ構成

- トップページ
- 由緒・境内案内(`about/`)
- おみくじ(`omikuzi/`)
- ご利益・授与所(`benefit/`)

## 使用技術

- HTML
- CSS
- JavaScript(おみくじの機能)

## こだわった点

- 和紙風の背景や、鳥居などの素材を使った、神社らしい雰囲気づくり
- 和文の読みやすさに配慮した文字組み
